# 图片转 PDF

一个带**连续滚动预览**的图片合成 PDF 工具：选一个文件夹（或直接拖入图片），调整页面
尺寸与排版，中间像看 PDF 一样上下滚动预览，一键导出。

界面使用 PySide6（Qt 6），图片处理使用 Pillow，文件 / 文件夹选择使用 `xdg_dialogs`。

## 依赖

```bash
python -m pip install -r requirements.txt
```

- `PySide6` —— 界面与预览
- `Pillow` —— 读取图片、渲染页面、写出 PDF
- `xdg-dialogs` —— 原生文件 / 文件夹选择对话框（未发布到 PyPI，需单独安装）

```bash
# 从本地源码安装（示例路径按实际情况修改）
python -m pip install -e /path/to/xdg_dialogs --config-settings editable_mode=compat
```

> 未安装 `xdg-dialogs` 时程序会自动回退到 Qt 自带的文件对话框，功能不受影响。

## 功能

- **连续预览（无限流）**：所有页面纵向排列，滚动到哪就渲染到哪，视口外的页面只占位、
  不渲染；页面缓存有内存上限，长时间浏览不会无限增长。
- **每页高度随图片**：
  - 「跟随每张图片」——每页 = 该图片的原始像素尺寸；
  - 「最宽图片」——宽度统一为最宽图片，每页高度 = 该图片自身高度；
  - 「自定义宽度」——高度可按比例缩放 / 保持原高 / 固定高度。
- **其他页面尺寸**：跟随第一张图片 / A4（纵横向，像素随 DPI 计算）。
- **图片布局**：适应页内（完整显示）/ 原始大小（超出裁剪）/ 拉伸填满，配合九宫格
  对齐与页边距。
- **图片顺序**：按文件名自然排序（`file2` 在 `file10` 之前），可拖动条目或用
  上移 / 下移调整，支持移除。
- **拖放**：把图片或文件夹拖进窗口即可载入。
- **后台导出**：生成过程在后台线程执行，带进度条与完成提示（可直接打开输出目录）。
- 无法读取的图片会被跳过并在状态栏提示，不会中断导出。

## 页面尺寸模式

| 模式 | 每页宽度 | 每页高度 | 示例（100×100、200×200 两张图） |
| --- | --- | --- | --- |
| 跟随每张图片 | 图片宽度 | 图片高度 | `100×100` + `200×200` |
| 最宽图片 | 最宽图片宽度 | 该图片自身高度 | `200×100` + `200×200` |
| 自定义宽度 · 随图片比例 | 自定义值 | 按宽度等比缩放 | `300×300` + `300×300` |
| 自定义宽度 · 保持原高 | 自定义值 | 图片自身高度 | `300×100` + `300×200` |
| 自定义宽度 · 固定高度 | 自定义值 | 自定义值 | 所有页同尺寸 |
| 跟随第一张图片 | 第一张图片宽 | 第一张图片高 | 所有页同尺寸 |
| A4 纸张 | 210 mm | 297 mm | 像素尺寸 = 毫米 × DPI ÷ 25.4 |

> **关于旧版**：`OLD/main.py` 对整份 PDF 只计算一组 `(width, height)`，A4 之外的
> 「跟随第一张图片 / 最宽图片 / 自定义宽度」也都是统一尺寸（多图时自定义高度默认取
> A4 高度），不会按图片长度逐页设置；超长图片会被裁剪。新版已补上逐页高度随图片的
> 多种模式。

## 使用

```bash
python main.py
```

也可以把 `OLD/run.sh` 复制到项目根目录使用（脚本会自动选择根目录下的 `main.py`
并优先使用 `.venv` 解释器）。

## 配置文件

程序会在 `main.py` 同目录自动创建 / 更新 `config.json`：

| 字段 | 说明 |
| --- | --- |
| `default_dir` | 默认路径，默认为空；文件对话框优先从这里打开 |
| `last_dir` | 上一次文件对话框所在目录（仅用于下次选择文件的起点） |
| `settings` | 上一次的页面尺寸 / 布局 / DPI 设置 |

- `default_dir` 为空时，文件对话框会打开上一次所在的目录。
- 启动时只恢复默认路径、上次目录和页面设置，**不会自动加载任何图片 / 上次任务**。
- 右侧「默认路径」卡片中的「恢复默认」会清空默认路径与上次目录，并重置全部设置和已选图片。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + O` | 选择图片文件夹 |
| `Ctrl + G` | 生成 PDF |
| 滚轮 / 拖动滚动条 | 连续浏览页面 |
| `Ctrl + 滚轮` | 缩放预览 |

## 支持的图片格式

`.jpg` `.jpeg` `.png` `.bmp` `.gif` `.tif` `.tiff` `.webp`

JPEG 的 EXIF 方向会被自动修正；动图只取第一帧。

## 说明

- 输出 PDF 的物理纸张尺寸 = 像素尺寸 ÷ DPI × 25.4 mm。默认 300 DPI，此时 A4 正好是
  2480 × 3508 像素。
- **跟随每张图片**会让页面宽度也随图片变化；若希望宽度统一、只让长度随图片，请使用
  「最宽图片」或「自定义宽度」。
- 「原始大小」模式按图片原始像素粘贴，超出页面内容区域的部分会被裁剪。
